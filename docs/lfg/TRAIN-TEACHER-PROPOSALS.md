# Train-only local teacher proposals

`ml/lfg-encoder/train_teacher_proposals.py` accepts a digest-pinned masked export only when its manifest lists `train.jsonl` as the sole split. It reads the manifest, export config and literal train file once, verifies their configured and manifest digests, then makes an exclusive owner-private snapshot of those exact bytes for `masked_supervision.load_export(train_only=True)`. It rechecks the source manifest/config/train bytes before transfer and publication. A manifest that lists validation or any other split is rejected before config/train access; a later manifest replacement cannot change the loader's pinned snapshot. Configuration may select row-ID digests and a bounded row count; source text is not stored in configuration.

The adapter requires a private `lfg.train-teacher-proposals-config.v1` JSON file. It pins the export manifest/config/train, taxonomy, screening policy and screening code digests, selected columns, row selection, byte bounds and private output location. It refers to the existing private local-comparison configuration and reuses its acquisition receipt, model artifact verification, runtime identity, resource rules and SSH host checks. Each actual run first completes a separate task-owned zero-row transient worker lifecycle: a unique owner-private remote directory, hash-verified adapter/comparator/config files, task-local model store, systemd resource scope, network namespace, same-user loopback service, worker readiness identity, and a host-namespace listener denial probe. The worker receives only an empty payload, performs its warmup, stops the service and verifies cleanup. The actual lifecycle requires the probe's host, model, runtime, config and code identities to match before it sends selected train rows. No long-running shared worker is used.

Python starts the staged worker with isolated mode. A small bootstrap verifies the exact config, adapter and sibling comparator digests before adding that staged directory to the import path, then starts the worker entry point. This keeps isolated startup compatible with the comparator dependency without admitting an unverified import path.

The worker now uses two control stages. It first reports the isolated runtime boundary without accepting payload; the controller verifies the host namespace cannot reach the loopback listener and returns a nonce-bound empty warmup acknowledgement. Only then does the worker warm up, verify the loaded model and artifact layer bytes, and issue a separate ready-for-data event. The controller checks those identities against the zero-row probe before sending any selected train rows. A denial or identity mismatch stops before data transfer.

```sh
python ml/lfg-encoder/train_teacher_proposals.py --config PRIVATE_CONFIG.json --zero-row-probe
```

The explicit `--zero-row-probe` command performs only that empty-input lifecycle and does not open export files or create a proposal report. The normal command repeats the probe automatically before opening any training payload to the worker. Before the first actual run, independently review the implementation and accept the standalone probe evidence.

Proposal results are published atomically to a new owner-private directory outside every Git worktree, with an incomplete marker retained if publication fails. The manifest binds export lineage, adapter/comparator/config/model hashes and receipt, host boundary, resource snapshots, row counts, per-label coverage, worker statuses and omission policy. JSONL stores row/source and screened/original-text digests, source target/mask/origin/reviewer claims, and proposal states; it excludes request bytes, raw responses, screened text and exception content. Teacher outputs are unreviewed claims and promotion-ineligible. By default omitted labels stay unknown; `assume_exhaustive_labels` is an explicit operator setting that records omitted labels as unreviewed negative proposals. Conflicts remain in both source claims and proposal results. A transport or worker failure with ambiguous inference lifecycle aborts all later rows as not attempted.

This adapter does not access validation, test or heldout rows and does not train a model. A successful probe or proposal run does not establish label accuracy, verified screening, model quality or promotion eligibility.
